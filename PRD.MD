# FekiTech Website Context

## 1. Project Overview

**Project Name:** FekiTech
**Website Type:** Premium business technology landing page
**Primary Goal:** Create a clean, dark, professional, responsive website for FekiTech that communicates the brand as a high-performance business operating system company.

FekiTech helps businesses move from chaos to structured performance by redesigning their operations, improving visibility, strengthening profitability, and supporting scalable growth.

The website should position FekiTech as a premium business intelligence, operational transformation, and digital systems company.

## 23. Visual and Motion Requirements

The website should include premium motion but must remain professional and smooth.

Use:

* Scroll reveal animations
* Soft parallax elements
* Floating dashboard elements
* Smooth hover states
* Animated line systems
* Testimonial marquee loops
* Stat count-up animation
* Subtle glowing borders
* Button hover effects
* Section transitions

Avoid:

* Excessive bouncing
* Cheap animation effects
* Fast distracting movement
* Overused purple gradient blobs
* Heavy 3D that affects performance
* Messy layouts
* Too many icons

Motion should communicate structure, clarity, and transformation.

## 29. Pre-Build Instructions for Codex

Before writing code:

1. Inspect the project folder.
2. Identify the tech stack.
3. Locate the FekiTech logo.
4. Check package files.
5. Check available design, frontend, motion, 3D, animation, or MCP skill folders.
6. Use any relevant skills that improve the design quality.
7. Recommend any missing library before installing it.
8. Do not install unnecessary heavy dependencies.
9. Preserve existing project structure if one exists.
10. Build with clean, maintainable components.
